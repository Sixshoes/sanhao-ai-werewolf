# 三好 AI 狼人殺（青嵐書院・清茗茶席 3D 互動反霸凌推理系統 v25.9.0）

一款將 **「三好（做好事、說好話、存好心）」** 與 **「四給（給信心、給歡喜、給希望、給方便）」** 融入社會推理規則的純網頁 3D 反霸凌桌遊。全站採免註冊、零外部 CDN 腳本依賴與 100% 盲審匿名架構，支援桌機、平板與手機跨裝置體驗，並內建五層自動化驗證流水線。

---

## 核心特色與系統架構（v25.9.0）

- **零洩漏盲視防弊架構（`js/ai/blind-view.js`）**：透過 JavaScript `Proxy` 陷阱與凍結快照隔離 AI 視角，非狼人角色無法讀取任何他席真實底牌或隱藏欄位，並於送出大型語言模型前執行 `auditLlmPromptLeak()` 靜態字串稽核（通過 496/496 項防弊壓力檢測，0 次洩漏）。
- **雙核四代理編排、雲端主力模型與配音代理**：集中編排器（`js/core/orchestrator.js`）統籌四大代理，雲端代理（`api/gemini.js`）以 `gemini-3.5-flash-lite` 為主力並支援 `gemini-3.8-flash`／`gemini-3.6-flash`／`gemini-2.5-flash-lite` 備援與本機 Ollama／本地引擎自動降級（嚴格過濾 Gemini 3+ 採樣與負向思考預算參數）；雲端配音代理（`api/tts.js`）整合 `gemini-3.8-flash-lite-tts` 為主力、`gemini-3.8-flash-tts` 與 `gemini-2.5-flash-preview-tts` 備援（16 種角色音色與核心音色降級）。
- **三好與四給實戰機制化**：
  - **顯性主動茶禮列、風氣三段生態與因果錄**：入席前先透過資源預載遮罩喚醒天穹與 3D 夥伴；白天階段於座次列下方常駐展開「三好四給主動茶禮列」與茶風指示，友善度即時牽動「清朗茶風／茶席平瀾／流言起霧」說服力與從眾效應，四給擋票護席與理線破霧獲 AI 致謝回響，終局呈現「三好四給因果錄」。
  - **三選一婉轉潤飾籤**：偵測尖銳字眼時展開「直指矛盾／溫言請教／留白觀望」三張選擇籤，保留玩家推理主導權。
  - **言行一致防偽善雷達**：跨輪比對口頭點名與實際投票，終局呈現「言語溫度 × 言行一致度」覆盤。
  - **四給奉茶策牌**：包含「奉茶護席（擋 1 票）」、「溫言破冰（觀微察脈）」、「明燈對質（15 秒雙向公開對質）」與「緩議歸票（關係連線）」。
- **臨場互動與視聽表現**：
  - **11 席專屬 3D 剪影與決策癖好**：CC0 `.vrm` 模型結合 PBR 材質（Poly Haven CC0）、青嵐書院／絕雲仙境雙 3D 古亭造景、220ms 吸氣預備拍、發言時全席視線齊聚、FFT 多母音即時對嘴與 1.25kHz 挖槽動態混音。
  - **舉杯追問與燭下覆茶**：白天可每日 1 次當場舉杯打斷並追問發言者原話破綻；夜晚無技能書院生可於燭光下圈選隔日盯防席位。
  - **四大青嵐奇局**：迷霧封牌局（不翻身分牌）、三分鐘閃電快棋（22 字＋15 秒快投）、雙刃毒茗局（首夜解禁清心茶）、孤狼流言王局（6 人無觀察員）。
- **評審 150 秒全亮點導覽局與終局覆盤升級**：
  - 首頁「更多模式 → 評審導覽」一鍵切入第 2 日五人聽牌雙觀察員對跳高潮盤面，搭配不遮擋三步提示，於 150 秒內依序體驗舉杯追問、三選一潤飾籤與五人聽牌公投。
  - 終局面板自動生成 **「本局三大勝負轉折軸」** 與 **「全席底牌與言行對照表」**，並支援一鍵複製或下載文字覆盤戰報。
- **PWA 雙池離線快取（`sw.js`）**：將核心程式碼（`sanhao-shell-v25.9.0`，Network-First）與不可變 3D／語音媒體（`sanhao-assets-v25.9.0`，Cache-First，上限 200 筆）分離管理，避免大型資產擠出核心腳本並確保版本即時更新。

## 快速啟動方式

### 方式一：本機完整啟動（啟用免費神經多角色台灣腔語音＋選配 Gemini / Ollama）
於專案根目錄執行：
```bash
python server.py
```
瀏覽器開啟 `http://127.0.0.1:8788/ai.html` 即可遊玩（預設僅監聽本機安全迴路，需區網測試時可加 `--lan`；環境變數設定 `GEMINI_API_KEY` 時自動啟用後端安全代理）。

### 方式二：純靜態網頁部署或離線開啟
專案根目錄含自動導向頁 `index.html` 與靜態 3D 資產清單 `assets/models/manifest.json`，所有前端腳本與 CSS 均已離線本地打包，可直接部署至任意靜態網頁空間，或直接以瀏覽器開啟 `ai.html` 離線運行。

## 五層自動化驗證

修改任何模組後，請於專案根目錄執行完整五層驗證：

```bash
node tests/run_all.mjs
```

驗證依序涵蓋：
1. `[1/5]` Python 後端語法編譯檢查（`py_compile server.py`）。
2. `[2/5]` 後端安全迴路、溫度夾限、ETag 與 TTS 快取單元測試（`tests/test_server.py`）。
3. `[3/5]` 全站靜態資源、10 隻 VRM、GLSL、零 `!important`、零 Emoji、匿名規範與端對端回歸測試（`tests/smoke.mjs`）。
4. `[4/5]` 60 局多規模多奇局亂數壓力與不變量測試（`tests/fuzz.mjs`）。
5. `[5/5]` 496 項零洩漏防弊 Proxy 壓力驗證（`tests/anti_cheat.mjs`）。
